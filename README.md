# 🌦️ Weather App

A simple weather web application built using **Flask**, **HTML**, **CSS**, and **JavaScript**. It provides real-time weather information for any city using the WeatherAPI.

## 🚀 Features

- Search weather by city name
- Current temperature (°C)
- Humidity
- Wind speed
- UV Index
- Weather condition
- Feels like temperature
- Pressure
- Weather icon

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- WeatherAPI
- Vercel (Deployment)

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Weather-App.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a `.env` file

```
API_KEY=YOUR_WEATHERAPI_KEY
```

4. Run the application

```bash
python app.py
```

5. Open your browser

```
http://127.0.0.1:5000
```
